# 鐵匠鋪 —— 習慣養成與任務管理系統
## Software Design Document v2

---

## 0. 設計初衷與硬性約束

這不是生產力工具，是一間鐵匠鋪。使用者是鐵匠，任務是原礦，完成任務是鍛造，展覽牆是多年打造下來的收藏室。

### 0.1 三條不可違背的約束

任何新功能若違反以下任一條，一律不做：

| 約束 | 來源特質 | 具體含義 |
|---|---|---|
| **啟動成本必須趨近於零** | 高標準保護型完美主義 | 任何功能的第一步不得要求使用者做出品質判斷 |
| **系統負責點火，不負責監督** | 外部觸發、內部燃燒 | 提供氛圍與入口，但不催促、不追蹤未完成 |
| **結構可自訂，流程不強制** | 掌控感驅動的創造者 | 所有預設值皆可改，所有步驟皆可略過 |

### 0.2 成功指標

- **主指標**：連續開啟天數（不是完成任務數）
- **次指標**：捕捉層使用頻率、傳承武器最高鍛造次數
- **明確排除**：任務完成率 —— 此數字不得出現在介面任何位置

### 0.3 v2 相對 v1 的變更摘要

| 項目 | v1 | v2 |
|---|---|---|
| 世界觀 | 無 | 三分支（現代／仙俠／魔法）+ 委託開場故事 |
| 武器外觀 | 使用者上傳圖片 | 每分支 10 種 skin，隨機抽取，無需上傳 |
| 詞條 | 前綴 + 名詞後綴 | 單純形容詞，各自帶顏色等級 |
| 品質決定 | 難度分數直接 roll | 詞條顏色平均值決定（見 §7.3） |
| 特殊詞條 | 無 | 奇物類別（銀灰色，7 種，純彩蛋） |
| 背景 | 靜態 | 10 種景深動物，一次一隻 |
| 刪除任務 | 無 | 回爐機制 + 確認視窗 |
| 展覽牆 | 單一樣式 | 三種分支背景 + 跨世界收藏設定 |

## 2. 世界觀分支系統

### 2.1 分支種類

`BranchType = "MODERN" | "XIANXIA" | "MAGIC"`

### 2.2 開場故事

僅首次啟動時顯示，**必須提供跳過按鈕**。

**現代／科技**
> 訊號在深夜接通。另一端的世界被異形佔據大部分的城市，他們的工廠早已停轉，剩下的人握著壞掉的槍，在遠離市區的小鎮生活。
> 「我們已經一無所有，但我們還有時間，可以等，等待神器鍛成之日，奪回我們的城市。」
> 你關掉通訊，打開爐子。訂單接下了。

**仙俠**
> 一封信自劍匣中浮出，字跡未乾。那界外域天魔入侵，門派凋零，練器師死傷殆盡，弟子手中無器可執。
> 「此去山高路遠，不知歸期。待器成之日，自有人來取。」
> 你將信收進袖中，起了爐火。

**魔法**
> 魔網的碎片使傳送陣亮了一瞬，落下一張羊皮紙。那個世界的魔網被摧毀，法師們的杖裂了，騎士的劍鏽了。
> 「我們會一直等。直到神器見證下一位英雄的誕生。」
> 你把紙釘在牆上，拉開風箱。

**敘事設計原則**：三段皆為「委託」而非「拯救」。有具體的對手、有等待的人，但**無期限、無倒數、無失敗條件**。鐵匠對訂單有掌控權，被拯救者對救世主沒有。

### 2.3 分支切換

- 入口位於左上角，與心情切換邏輯相同（隨時可改，不需確認）
- 切換後影響：新造武器的 skin 池、展覽牆背景、動物配色風格
- **已造出的神器保留原 skin，永不變更**
- 選擇介面必須顯示說明文字：「隨時可以換，換了之後打的東西才會變。」
  - 目的：降低初始選擇的決策壓力，明確告知後果可逆

### 2.4 跨世界收藏（設定說明）

切換分支後，展覽牆背景為當前分支，但舊藏品保留原世界的 skin。此現象在系統中**明確定義為設定而非 bug**：這些是你從別的世界帶回來的東西。牆面隨使用時間逐漸成為跨世界收藏室。

## 3. 武器 Skin 系統

### 3.1 抽取規則

- **完全隨機**，10 種等機率，不受稀有度或難度影響
- 理由：稀有度已由顏色明確表現，skin 加權會造成系統重複，並產生「金色但只是手槍」的落差感
- **EPIC（史詩神器）**：每把完成時重新抽取
- **LEGACY（傳承武器）**：首次鍛造時抽定，**永久不變**
  - 理由：傳承武器需陪伴數十次鍛造，skin 變動會破壞情感依附
- 完成後提供**一次免費「重鑄外觀」**：僅重抽 skin，不影響詞條與品質

## 4. 資料模型

### 4.1 Task

```
Task {
  id:            string
  title:         string
  type:          "EPIC" | "LEGACY"
  status:        "CAPTURED" | "ACTIVE" | "PAUSED" | "COMPLETED" | "MELTED"
  tag:           "URGENT" | "DAILY" | null
  difficulty:    int 1–10 | null
  branch:        BranchType          // 建立當下的分支，永不變更
  skin_id:       int 1–10 | null     // LEGACY 首次鍛造後鎖定
  reforge_used:  boolean             // 重鑄外觀是否已使用
  created_at:    timestamp
  promoted_at:   timestamp | null
  milestones:    Milestone[]         // 僅 EPIC
  forge_count:   int                 // 僅 LEGACY
  forge_records: ForgeRecord[]       // 僅 LEGACY
  traits:        Trait[]
  quality:       QualityColor | null // 由詞條計算得出，見 §7.3
  logs:          LogEntry[]
}
```

### 4.2 Milestone（僅 EPIC）

```
Milestone {
  id: string, label: string, percent: int 1–100,
  completed: boolean, completed_at: timestamp | null, note: string
}
```

進度條數值 = 已完成節點中 percent 的最大值。無節點時以手動百分比為準。

### 4.3 ForgeRecord（僅 LEGACY）

```
ForgeRecord {
  forge_index: int, forged_at: timestamp,
  mood_at_time: MoodState, power_gain: int, note: string | null
}
```

### 4.4 Trait

```
Trait {
  text:        string              // 形容詞本體，如「鋒利的」
  tier:        1–5 | "CURIO"       // 1=灰白 … 5=金，CURIO=奇物
  level:       int                 // 1=原始，2+ 顯示為「鋒利的+」
  obtained_at: timestamp
  source:      "INITIAL" | "MILESTONE_3" | "MILESTONE_7" | "MILESTONE_21" | "MILESTONE_50"
}
```

### 4.5 DayLog

```
DayLog {
  date: date,                                          // 一天一筆
  mood_tag: "TENSE"|"CALM"|"TIRED"|"EXCITED"|"NUMB",
  free_text: string | null,                            // 選填

```

### 4.6 UserSettings

```

}
```

## 5. Layer 0：心情簽到

### 5.1 互動規格

- 開啟後**唯一**首屏內容，不顯示任務、不顯示牆面
- 單句對話式提問，五個情緒標籤按鈕，點擊即完成
- `free_text` 為選填，可完全略過
- 全程 ≤ 2 秒、≤ 1 次點擊

### 5.2 mood_state 四向映射

| mood_tag | 任務密度 | 節點密度 | 牆面氛圍 | 詞條前綴傾向 | 動物池 |
|---|---|---|---|---|---|
| TENSE 緊繃 | 3 項（1緊急+2日常） | 只展開最近一個未完成節點 | 冷白光、低飽和、無背景音 | 淬鍊系 | 全部 |
| CALM 平靜 | 全部 | 全部可見 | 暖黃光、標準飽和 | 靈感系 | 全部 |
| TIRED 疲憊 | 1 項（鍛造次數最高的 LEGACY） | 只展開最小節點 | 極暗、餘燼感、極輕環境音 | 意志系 | 安靜組 |
| EXCITED 興奮 | 全部 + 捕捉層一併展開 | 全部可見 | 高對比、爐火旺盛、火花粒子 | 靈感系（高階詞條權重 +10%） | 全部 |
| NUMB 麻木 | 1 項日常 | 只展開最小節點 | 灰階、靜止 | 意志系 | 安靜組 |

> 設計註記：TIRED / NUMB 刻意極簡，此狀態下多顯示一個任務都是負擔。EXCITED 是唯一主動展開捕捉層的狀態 —— 那正是內部燃燒已啟動的時刻，適合做需要判斷力的升格動作。

## 6. Layer 1–2：捕捉層與定義層

### 6.1 捕捉層規格

- 浮動輸入框固定於畫面下緣，任何頁面皆可見
- 純文字 + Enter 建立，status 直接寫入 `CAPTURED`
- 建立時 `tag`、`difficulty`、`type` 全為 null，**不詢問任何問題**
- 暫存區僅顯示文字 + 相對時間（「3 天前」）

### 6.2 安全區保證（硬性規則）

捕捉層項目**永久不觸發**：

- ❌ 紅點、未讀數、badge
- ❌ 逾期標記、顏色變化、字體變灰
- ❌ 推播、提醒、彈窗
- ❌ 任何數量提示（如「你有 12 個未處理項目」）

項目數量無上限，不因時間久遠產生任何視覺變化。

### 6.3 升格流程

使用者主動點擊 → 定義層表單 → 選 type、tag、difficulty（EPIC 另可設節點）→ status 轉 `ACTIVE`。

升格為**唯一**需要判斷的操作，且完全由使用者發起。

### 6.4 難度分數輸入

- 1–10 滑桿，提問文案：「**這件事對你來說有多難？**」（主觀掙扎程度，非客觀工作量）
- 預設值 5，可直接送出
- 錨點提示：3 =「不太需要心理準備」、7 =「需要推自己一把」、10 =「一直在逃避這件事」

## 7. 詞條與品質系統

### 7.1 詞條庫（50 個形容詞）

**灰白・凡鐵（tier 1，12 個）**
鈍的、樸素的、粗糙的、沉重的、老舊的、普通的、暗淡的、笨拙的、單薄的、生鏽的、廉價的、無銘的

**綠・精鋼（tier 2，12 個）**
鋒利的、堅固的、輕巧的、平衡的、可靠的、耐用的、順手的、扎實的、乾淨的、溫熱的、安靜的、俐落的

**藍・秘銀（tier 3，10 個）**
精準的、冷冽的、迅捷的、通透的、韌性的、穩定的、鋒銳的、澄澈的、致密的、無聲的

**紫・符文（tier 4，8 個）**
熾烈的、共鳴的、不朽的、深邃的、貫穿的、逆流的、灼心的、蟄伏的

**金・傳說（tier 5，3 個）**
唯一的、寂靜的、破曉的

> 金色僅 3 個為刻意設計：金詞條的價值在於使用者叫得出它的名字。若有 12 種金詞條，抽到金色的記憶點會被稀釋。

### 7.2 奇物詞條（CURIO，7 個）

**顏色**：白銀 + 灰色參雜（漸層／流動的銀灰，非純色）
**設計意義**：銀灰在五色體系外，視覺上一眼可辨「這條不參與品質」，不與金色混淆

誠實的、無用的、醜陋的、傷敵一千自損八百的、會叫的、話很多的、認生的

**規則**：
- **全部為純彩蛋，無任何數值效果**
- 不參與品質計算
- 一把武器最多持有 1 個奇物詞條
- 出現機率：佔全詞條池約 10%

> 奇物的功能不是數值，是記憶點。一把「會叫的」劍放在展覽牆上，每次看到都會想起這件事。

### 7.3 品質計算規則

依序執行：

1. **基礎值** = 所有非奇物詞條的 tier 平均，四捨五入
2. **金色保底**：若任一詞條 tier = 5，品質至少為紫（tier 4）
3. 奇物詞條全程不參與計算

**範例**：
- 綠綠藍 → (2+2+3)/3 = 2.33 → **綠**
- 綠綠金 → (2+2+5)/3 = 3 → 藍 → 金色保底 → **紫**
- 金（單詞條）→ 5 → **金**

> **自然湧現的特性**：詞條數少的武器，品質更容易極端化。單詞條武器的品質即為該詞條本身，因此低難度任務（詞條較少）出金機率反而高於高難度任務。此特性予以保留 —— 它與「順手完成小事也可能爆金」的設計意圖一致。

### 7.4 品質顏色與視覺效果

| 品質 | 顏色 | 視覺效果 |
|---|---|---|
| 凡鐵 | `#9CA3AF` 灰白 | 無 |
| 精鋼 | `#4ADE80` 綠 | 邊框微光 |
| 秘銀 | `#60A5FA` 藍 | 邊框流光 |
| 符文 | `#A78BFA` 紫 | 邊框流光 + 符文浮動 |
| 傳說 | `#FBBF24` 金 | 全牆短暫變暗 + 聚光 + 火花粒子 |
| 奇物標記 | 銀灰漸層 | 詞條本身以流動銀灰呈現 |

LEGENDARY 的「全牆變暗聚光」是全系統最強視覺事件，不設冷卻限制。

### 7.5 EPIC 詞條數量與 tier 抽取權重

difficulty 決定**詞條數量**與**各 tier 抽取權重**：

| difficulty | 詞條數 | tier1 | tier2 | tier3 | tier4 | tier5 |
|---|---|---|---|---|---|---|
| 1–2 | 1 | 62% | 25% | 9% | 3% | 1% |
| 3–4 | 1–2 | 42% | 33% | 17% | 6% | 2% |
| 5–6 | 2 | 25% | 35% | 26% | 11% | 3% |
| 7–8 | 2–3 | 12% | 28% | 36% | 19% | 5% |
| 9–10 | 3 | 5% | 18% | 37% | 31% | 9% |

**關鍵原則**：每一列的 tier5 皆 > 0。低難度任務保留 1% 金詞條機率 —— 這個微小可能性是「順手完成小事」的隱藏獎勵。

奇物詞條獨立判定：每把武器有 **10%** 機率額外獲得 1 個奇物詞條，與 difficulty 無關。

### 7.6 LEGACY 次數門檻與強化

| forge_count | 事件 | 詞條變化 |
|---|---|---|
| 1 | 初次鍛造成形 | 獲得 1 條初始詞條（tier 依 difficulty 抽取，同 §7.5 表格 1–2 列） |
| 3 | 第一次回爐 | roll：60% 新增詞條 / 40% 既有詞條 +1 級 |
| 7 | 第二次回爐 | roll：50% 新增 / 50% 升級 |
| 21 | 第三次回爐 | roll：40% 新增 / 60% 升級 |
| 50 | 終焉鍛造 | 必定新增 1 條 + 全部既有詞條 +1 級 |

- 品質隨詞條變化自動重算（同 §7.3）
- difficulty 不影響 tier，只影響 `power_gain`，累積為「鍛造熱度」（純展示，如「熱度 138」）
- 第 50 次後不再有門檻，但 forge_count 持續累加並顯示
- **中斷不懲罰**：無 streak、無斷線提示、無武器損壞。三個月未鍛造，回來時從原次數接續

> 為何不做 streak：連續天數是典型的「一次失誤全毀」機制，會直接觸發「差距過大時癱瘓」的模式。次數制只會前進，不會後退。

## 8. 核心體驗時刻：鍛造完成動畫

全系統最重要的 3 秒，規格須嚴格執行：

| 時間 | 階段 | 內容 |
|---|---|---|
| 0–0.8s | 蓄力 | 其餘元素降低亮度，武器卡片居中放大 |
| 0.8–1.5s | 敲擊 | 鐵錘音效 × 3 下，每下伴隨火花粒子與畫面微震 |
| 1.5–2.3s | 顯現 | skin 輪廓浮現，品質顏色由中心擴散，邊框點亮 |
| 2.3–3.0s | 刻銘 | 詞條文字逐字浮現，如同刻上器身 |

詞條**必須在此刻才生成並揭曉**，不得預先顯示或提前計算後展示。開獎的不確定性是動機系統的核心來源。

奇物詞條在刻銘階段**最後**出現，以銀灰流動效果單獨浮現。

## 9. 回爐機制（Melt）

### 9.1 設計意義

回爐不是刪除，是**給「放棄一個任務」一個體面的出口**。鐵匠回爐是日常操作，不是失敗 —— 那塊鐵還在，只是這次形狀不對。

### 9.2 規格

- **主要開放對象：未完成的神器**（status = ACTIVE / PAUSED）
- **已完成神器（COMPLETED）不開放回爐**，或需進入設定深層才可執行
  - 理由：完成品是資產，不該有隨手刪的入口，否則會誘發「整理收藏」的完美主義消耗
- 執行後 status → `MELTED`，自展覽牆與任務列表移除
- **確認視窗必要**，文案採老鐵匠語氣

### 9.3 確認視窗文案

> **回爐重來。這把就不留了。**
> [ 回爐 ]　[ 再看看 ]

**禁止事項**：
- ❌ 不詢問理由
- ❌ 不顯示已投入時間 / 已完成百分比
- ❌ 不出現「確定要放棄嗎」等挽留字眼

### 9.4 暫停機制（PAUSED）

LEGACY 可手動設為 `PAUSED`：

- 自主畫面隱藏，但**保留在展覽牆上**，forge_count 完整保留
- 牆上顯示為「靜置中」樣式（微暗、爐火熄滅，但不破損、不灰階）
- 可隨時恢復，次數接續
- 文案統一使用「靜置」，不得出現「放棄」「中斷」「失敗」

## 10. 展覽牆

### 10.1 分支背景

| 分支 | 背景 | 裝飾細節 |
|---|---|---|
| MODERN | 科技實驗室 | 金屬層架、冷光燈條、玻璃展櫃反光 |
| XIANXIA | 陣法煉器室 | 石台、懸浮陣紋、緩慢流動的靈氣 |
| MAGIC | 鐵匠鋪 | 木質層架、爐火餘光，**邊緣龍頭裝飾** |

**龍頭裝飾約束**：置於畫面邊緣，**不得遮擋任何神器展示區域**。建議置於左下或右下角，佔畫面寬度 ≤ 12%。

### 10.2 版面配置

採分區網格，由上而下三區：

1. **鍛造中** —— 進行中的 EPIC + ACTIVE 的 LEGACY，卡片較大
2. **已成之器** —— COMPLETED 的 EPIC，依品質由高至低排序
3. **靜置區** —— PAUSED 項目，收合狀態，需點擊展開

> 進行中置於**最上方**：確保每次開牆第一眼看到的是「我正在打造的東西」，而非「我還差多遠」。

### 10.3 殘缺度視覺（程序化，不需使用者投入）

未完成的 EPIC 以程序化方式呈現殘缺：

- skin 的 SVG 路徑依進度百分比逐段顯現，未顯現區域以爐火餘燼色的雜訊紋理填充
- 交界處加暖色漸層光暈，模擬「正在淬鍊出來」
- 全自動計算，使用者無任何額外操作
- **v2 不再需要使用者上傳圖片**（skin 系統已取代此需求）

### 10.4 卡片顯示資訊

| 欄位 | EPIC | LEGACY |
|---|---|---|
| 名稱 | ✓ | ✓ |
| skin 圖像 | ✓ | ✓ |
| 品質顏色框 | ✓ | ✓ |
| 詞條列表 | 完成後顯示 | 隨門檻逐步顯示 |
| 進度百分比 | ✓ | ✗ |
| 鍛造次數 | ✗ | ✓「鍛造 N 次」 |
| 鍛造熱度 | ✗ | ✓ |
| 來源分支標記 | ✓（僅當與當前分支不同時顯示） | ✓（同左） |

## 11. 背景動物系統

### 11.1 設計意義

動物是**唯一一個與任務完成度完全脫鉤的開啟誘因**。系統主指標為「有沒有打開」，而動物直接服務此指標 —— 不需要使用者做任何事就會發生。

### 11.2 動物清單與景深規格

比例不採真實尺寸（鯨魚與蝸牛差 800 倍，物理上無法同框）。改採**視覺大小 = 真實大小 ÷ 距離**的景深模型，透明度作為深度線索。

| 動物 | 景深層 | 畫面寬度佔比 | 透明度 | 移動速度 | 停留時間 | 安靜組 |
|---|---|---|---|---|---|---|
| 鯨魚 | 極遠（天空） | 22% | 10% | 極慢橫向 | 25s | ✓ |
| 鹿 | 遠（地平線） | 8% | 12% | 靜止為主 | 40s | ✓ |
| 紙鶴 | 中遠 | 5% | 15% | 慢速盤旋 | 15s | |
| 螢火蟲群 | 中（散佈景深） | 每點 0.4% | 18% | 極慢飄移 | 30s | ✓ |
| 狐狸 | 中 | 10% | 15% | 中速、會停頓 | 12s | |
| 貓 | 中近 | 13% | 15% | 慢走、會坐下 | 20s | |
| 貓頭鷹 | 中近 | 11% | 15% | 靜止、偶爾轉頭 | 35s | ✓ |
| 錦鯉 | 近（畫面下緣） | 15% | 12% | 慢速游動 | 18s | |
| 烏龜 | 近（地面） | 9% | 15% | 極慢 | 30s | |
| 蝸牛 | 極近（貼邊框） | 6% | 20% | 極慢 | 40s | ✓ |

> 判讀方式：鯨魚佔畫面 22% 但透明度僅 10%，讀作「很遠、很大」；蝸牛僅佔 6% 但透明度 20%（相對清晰），讀作「很近、很小」。

### 11.3 排程規則

- **同時最多 1 個實例**（螢火蟲群整群算 1 個）
- 離場後間隔 **60–180 秒隨機**，才出現下一個
- 抽取時**排除上一次出現的種類**，避免連續重複
- TIRED / NUMB 狀態：抽取池限縮為安靜組（鯨魚、鹿、螢火蟲群、貓頭鷹、蝸牛），間隔拉長為 **180–300 秒**
- 抽取範圍僅限 `UserSettings.animal_enabled` 中啟用的種類

### 11.4 使用者自選

- 設定頁提供 10 種動物的開關清單
- **不設稀有度、不設圖鑑、不顯示收集進度**
  - 理由：一旦出現「3/12」的進度提示，動物就從驚喜退化為待辦清單

### 11.5 輸入專注模式（Input Focus Mode）

- **觸發**：捕捉層輸入框或任務日誌輸入框取得焦點
- **效果**：動物透明度 × 0.4，動畫速度 × 0.5
- **計時器繼續走**，動物不消失、不重置
- 失去焦點後 **1.5 秒內漸變回原值**（不得瞬間跳回）

> 設計意圖：牠還在，只是安靜下來了 —— 像真的有隻貓在旁邊看你工作，而不是你一動筆牠就跑掉。

### 11.6 分支配色

同一組動物資產依分支換配色，成本低但世界觀濃度顯著提升：

| 分支 | 風格 |
|---|---|
| MODERN | 全息投影感、掃描線、藍青色調 |
| XIANXIA | 水墨感、雲氣繚繞、墨與淡金 |
| MAGIC | 微光粒子、柔和輝光、暖紫調 |

## 14. 文案規範

介面文案直接決定系統會不會被使用者的心理防禦機制排斥。

**核心語氣定位：一位話不多的老鐵匠。陳述事實，不評價，不催促，不打氣。**

### 14.1 禁用清單

| 禁用 | 原因 | 替代 |
|---|---|---|
| 「你已經 X 天沒有…」 | 觸發罪惡感循環 | 「上次鍛造在 X 天前」（中性陳述）或不提 |
| 「完成率 X%」 | 觸發完美主義評判 | 完全不顯示 |
| 「加油！你可以的！」 | 空泛激勵，會引發反感 | 中性描述當前狀態 |
| 「連續 X 天中斷」 | 一次失誤全毀 | 不做 streak 機制 |
| 「放棄 / 失敗 / 逾期」 | 負面標籤 | 「靜置」「回爐」 |
| 「建議你先完成…」 | 說教式指導 | 陳述事實，讓使用者自行決定 |

### 14.2 語氣範例

| 情境 | ❌ 錯誤 | ✓ 正確 |
|---|---|---|
| 心情簽到後 | 「今天也要好好努力喔！」 | 「爐火已經升起來了。」 |
| 疲憊狀態進入 | 「休息夠了就開始吧」 | 「今天只留一件事在檯面上。」 |
| 長期未鍛造後回歸 | 「你已經 30 天沒有鍛造了」 | 「這把還在，第 12 次鍛造。」 |
| 完成低品質 | 「只拿到普通品質」 | 「凡鐵。也是鐵。」 |
| 抽到奇物詞條 | 「你獲得了負面詞條」 | 「這把會叫。原因不明。」 |
| 回爐確認 | 「確定要放棄這個任務嗎？」 | 「回爐重來。這把就不留了。」 |
| 捕捉層多筆未處理 | 「你有 12 個待辦事項」 | （不顯示任何數量提示） |

## 15. 開發範圍與優先順序

### 15.1 風險提示

本文件的素材量偏大：30 個 skin、5 種品質特效、10 種動物動畫、3 種牆面背景。素材製作正好落在使用者最危險的區域 ——「完成度不高就不會想多費心思」。

**若先做完整版，極可能停在第 12 個 skin，專案就此擱置。**

因此以下 MVP 範圍為**強烈建議的執行順序**，而非參考建議。

### 15.2 MVP 範圍（先做到這裡就可以上線使用）

| 模組 | MVP 內容 |
|---|---|
| 分支 | **僅 1 個分支**（建議先做使用者最有感的） |
| Skin | **3 種**（其餘 7 種先以佔位圖形處理） |
| 動物 | **3 種**（建議：貓、鯨魚、螢火蟲群 —— 涵蓋三種景深） |
| 牆面背景 | **1 種**（對應所選分支） |
| 心情簽到 | 完整 5 種 mood + 四向映射 |
| 捕捉層 | 完整（含安全區規則） |
| 定義層 | 完整 |
| EPIC | 完整（進度條、節點、詞條 roll、鍛造動畫） |
| 詞條庫 | 完整 50 + 7（純文字，成本低） |
| 回爐 | 完整 |
| LEGACY | 完整 |

> 詞條庫與文案為純文字資產，成本極低，應在 MVP 就做完整 —— 它們提供的體驗豐富度遠高於製作成本。

### 15.3 MVP 後擴充順序

| 階段 | 內容 |
|---|---|
| P1 | 補齊所選分支剩餘 7 個 skin |
| P1 | 補齊剩餘 7 種動物 + 輸入專注模式 |
| P2 | 第二個分支（故事 + 10 skin + 牆面背景 + 動物配色） |
| P2 | 展覽牆氛圍隨 mood 動態變化 |
| P2 | Spotify 深層連結 + 歌單對應 |
| P3 | 第三個分支 |
| P3 | 心情日誌月曆回顧 |
| P3 | 重鑄外觀功能 |

### 15.4 自我對照

> 這個專案本身應套用系統自己的規則：傳承武器的價值來自累積次數，不是第一次就完美。MVP 是第 1 次鍛造，不是成品。

## 16. 反模式清單（明確不做）
