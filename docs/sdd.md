# 鐵匠鋪 —— 習慣養成與任務管理系統
## Software Design Document (SDD)

---

## 0. 設計初衷

這不是一個生產力工具，是一個鐵匠鋪。你是鐵匠，任務是原礦，完成任務是鍛造，展覽牆是你多年打造下來的收藏室。

系統的每一個設計決策，都圍繞著使用者的三個核心特質展開：

1. **高標準保護型完美主義** —— 「開始」這個動作必須被刻意做輕，否則系統不會被使用
2. **外部觸發、內部燃燒** —— 系統要負責點火（心情日誌、氛圍調整），但不強迫燃燒的節奏
3. **掌控感驅動的創造者** —— 給空間、給入口，不給時間表、不給死板框架

**核心成功指標不是「完成了多少任務」，而是「今天有沒有打開這個網頁」。**

## 2. 核心功能模組

### 2.1 開場：心情日誌（Day Mood Check-in）

**觸發時機**：每次開啟網頁，第一件事。

**互動形式**：**不是表單，是一句話對話式提問**。例如：
> 「今天感覺怎麼樣？」→ 使用者輸入自由文字，或點選幾個輕量情緒標籤（如：緊繃／平靜／疲憊／興奮／麻木）

**資料用途（單一輸入，三種輸出）**：

| 輸出對象 | 影響方式 |
|---|---|
| 任務呈現密度 | 狀態偏低（疲憊/緊繃）→ 只顯示 1-2 個最小節點；狀態偏高 → 顯示完整任務列表 |
| 展覽牆氛圍 | 燈光色溫、背景音效隨心情微調（例如疲憊時牆面偏暖、安靜） |
| 詞條前綴機率池 | 記錄「完成當下」的心情，用於後續詞條生成（見 4.2） |

**設計原則**：這一步永遠是**當日第一個、且唯一必須做**的互動。做完這一句話，其他一切都是選擇性的。

---

### 2.2 捕捉層（Quick Capture）

**目的**：把「我想到一件事」跟「我要正式規劃這件事」徹底切開，避免捕捉本身變成啟動門檻。

**互動**：一個永遠可見的浮動輸入框（類似快速筆記），打字 + Enter 即完成，無需選分類、無需設難度、無需設節點。

**資料狀態**：進入「未分類暫存區」，以清單形式呈現，僅顯示文字內容 + 建立時間。

**後續動作**：使用者在狀態好、想動的時候，主動把暫存項目「升格」進定義層。未升格的項目**不會有任何提醒、不會有紅點、不會被標記為逾期**——捕捉層是安全區，不施加壓力。

---

### 2.3 定義層（Task Definition）

當使用者決定認真處理一個任務時，在此設定：

| 欄位 | 說明 |
|---|---|
| 任務類型 | 史詩神器（緊急/一次性） 或 傳承武器（日常/習慣） |
| 難度分數 | 1-10，使用者主觀評分「這件事對我來說有多難」 |
| 節點（僅史詩神器需要） | 依百分比設定小節點，可展開查看 |
| 任務日誌 | 自由文字，記錄過程中的想法、卡點、心得 |

**分類只保留兩種標籤：緊急、日常。** 不設「重要但不緊急」等複雜矩陣，避免分類本身變成決策負擔。

---

## 3. 兩種神器類型

### 3.1 史詩神器（緊急/一次性任務）

- 對應：有明確終點的任務或目標
- 進度條：依節點百分比推進，每個節點可展開查看細節與任務日誌
- 完成時：觸發**一次性詞條 roll**，稀有度依難度分數對應機率池決定（見 4.1）
- roll 完成後定型，不再變動，正式上牆

### 3.2 傳承武器（日常/習慣任務）

- 對應：重複性習慣（例如：每日運動、閱讀、早睡）
- 沒有「完成」的概念，只有**鍛造次數累積**
- 每次完成該習慣 = 一次鍛造，鍛造次數 +1
- 稀有度不是一次決定，而是隨累積次數推進（見 4.3）
- **武器不會因為某天沒做而損壞或消失**，只是那天沒有鍛造，下次開始鍛造時接續原本的次數繼續累加
- 上牆時額外顯示「鍛造 N 次」字樣，此數字本身即是里程碑展示

---

## 4. 詞條與稀有度系統

### 4.1 史詩神器：單次爆發邏輯

難度分數（1-10）直接對應一次性機率池，完成當下 roll 一次定生死。

| 稀有度 | 顏色 | 對應難度傾向 | 詞條數量 |
|---|---|---|---|
| 凡鐵 Common | 灰白 | 低難度 | 1 條 |
| 精鋼 Uncommon | 綠 | 中難度 | 1-2 條 |
| 秘銀 Rare | 藍 | 中高難度 | 2 條 |
| 符文 Epic | 紫 | 高難度 | 2-3 條 |
| 傳說 Legendary | 金（附特殊光效） | 極高難度 | 3 條 |

原則：難度分數只決定**機率傾向**，不保證結果——簡單任務也保留極小機率爆出高稀有度，維持「開獎感」的不確定性。

### 4.2 詞條內容（現階段：純裝飾性）

詞條由「前綴（心情）× 後綴（風格）」組合而成，完成瞬間才生成，不預先顯示。

**前綴（依完成當下的心情日誌狀態決定機率傾向）**

| 心情類別 | 前綴詞庫（範例） |
|---|---|
| 緊繃／壓力 | 熾焰的、鍛燒的、不屈的 |
| 平靜／穩定 | 靜謐的、清晰的、流動的 |
| 疲憊但仍完成 | 頑強的、破曉的、餘燼的 |

**後綴（純風格詞條庫，隨機抽取）**
巨人殺手、鋒利、破魔、迅捷、沉默、貫穿、不朽、精準、狂暴、守護者之刃、暗影行者、共鳴、餘震、無畏

> 註：此詞條庫為初版草稿，正式開發時需擴充為完整組合池（前綴 × 後綴），並可依使用習慣持續增補。目前刻意不賦予任何數值/功能，保留未來擴充彈性（例如集滿特定系列詞條解鎖展覽牆特殊展區）。

### 4.3 傳承武器：累積成長邏輯

- 難度分數（1-10）**不決定稀有度**，只決定每次鍛造的「強化值」大小（分數高 = 該次疊加幅度較大）
- 稀有度顏色隨**累積鍛造次數**推進，門檻：**第 3 次 / 第 7 次 / 第 21 次 / 第 50 次**
- 每達到門檻，觸發一次強化 roll：可能升級既有詞條（如「鋒利」→「鋒利+」），也可能新增一條詞條
- 詞條前綴同樣依當次完成時的心情日誌狀態決定傾向

## 5. 展覽牆（Trophy Wall）

### 5.1 殘缺度視覺呈現（不依賴使用者上傳圖片）

**問題**：若殘缺度需要使用者手動處理圖片，會違背「低完成度不想費心思」的核心心理，且非 AI 系統本身無圖片生成能力。

**解法**：
- 完成品圖片（100% 完成時的樣子）由使用者自行以 AI 工具生成後上傳，**僅需一張**
- 未完成期間，系統以 **程序化 SVG 視覺** 呈現殘缺狀態：例如以 clip-path／遮罩技術，讓完成圖隨進度百分比由下往上「淬鍊顯現」，或以破碎三角形碎片隨進度逐漸拼合
- 此效果全自動計算，使用者無需為殘缺度做任何額外操作
- 若使用者選擇不上傳圖片，可退回純文字 + 鍛造光效呈現，圖片為可選項而非必要項

### 5.2 牆面內容

- **進行中**與**完成**的神器/武器同時展示，進行中項目以半透明/雕琢中樣式呈現，避免牆面顯得空蕩而觸發「差距過大癱瘓」
- 傳承武器旁顯示「鍛造 N 次」
- 史詩神器顯示稀有度顏色框 + 詞條
- 牆面燈光氛圍受當日心情日誌影響（見 2.1）

## 6. 音樂功能

**實作方式**：**深層連結（Deep Link）跳轉，非網頁內嵌播放**

- 於鍛造介面提供「開啟 Spotify」按鈕，點擊後跳轉至使用者預先設定的鍛造專屬歌單或歌曲
- 不採用 Spotify Web Playback SDK 內嵌播放，避免 Premium 帳號要求、OAuth 授權等技術成本
- 未來若有需求，可視情況升級為內嵌播放器

---

## 7. 任務日誌

- 每個任務（史詩神器 / 傳承武器）皆附帶自由文字日誌欄位
- 用於記錄過程中的想法、卡點、突破時刻
- 呼應使用者「輸出型思考者」特質：日誌不是紀錄用途，是幫助使用者透過書寫釐清思路的工具，介面應鼓勵隨手記，不設字數/格式限制

---

## 8. 互動設計原則（貫穿全系統）

依據使用者人格畫像，以下原則適用於所有介面文案與互動流程設計：

1. **不給時間表，給入口** —— 任何功能的第一步必須是最小、最不需要判斷的動作
2. **說結論，不說教** —— 系統提示文字避免命令句，改用描述性語句讓使用者自行得出行動意願
3. **先認可，再延伸** —— 若系統有回饋文字（如心情日誌後的回應），先反映使用者輸入內容，再溫和延伸，不評價
4. **不用罪惡感提示** —— 絕不出現「你已經 X 天沒有完成」等提示；改用「現在有什麼條件可以開始」的中性語氣，或乾脆不提示
5. **給創造空間，不給死板框架** —— 節點、分類、詞條皆保留使用者自訂彈性，避免過度預設結構

## 9. 待開發項目優先順序（建議）

| 優先級 | 模組 |
|---|---|
| P0 | 捕捉層、定義層基礎架構、心情日誌 |
| P0 | 史詩神器：進度條、節點、詞條 roll（單次邏輯） |
| P1 | 傳承武器：鍛造次數累積、強化 roll（次數門檻邏輯） |
| P1 | 展覽牆：程序化 SVG 殘缺度呈現 |
| P2 | 音樂深層連結 |
| P2 | 展覽牆氛圍隨心情日誌動態調整 |
| P3 | 詞條組合池擴充、特殊展區解鎖機制 |

## 10. 待確認 / 開放事項

- 詞條組合池的完整清單（目前僅提供草稿範例）
- 傳承武器強化 roll 的具體數值公式（強化值 × 難度分數的換算方式）
- 展覽牆版面配置（網格 / 自由排列 / 分區）尚未定案
- 是否需要「暫停」某個傳承武器的機制（例如習慣暫時中止但不想刪除歷史紀錄）
