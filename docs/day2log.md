## 2 · test.md 貼上沒反應

**結論：不是 bug。** Chrome DevTools 內建 self-XSS 防護，任何網站的 Console 貼程式碼都會先擋一次，要手動打 `allow pasting` 才放行，跟這個專案無關。

**做法**：`docs/test.md` 開頭加提醒（含同時出現、已確認無關的 `file://` frame 錯誤訊息，避免重複問同一個問題）。

**檔案異動**：`docs/test.md`

## 4 · 新增真實圖片動物——狗

使用者提供 4 張真實跑步循環圖片（`dog_1.png` ~ `dog_4.png`），要求做成背景動物。**原本 10 種之外的第 11 種，sdd-v2 沒有規格**，也是第一次用真實圖片而非程序化 SVG。

**跟前一天架構的關係**：day1 已經把動物系統改成「2 幀真的互相切換」，這次是在同一套架構上擴充幀圖來源，不是重做：

| 檔案 | 改動 |
|---|---|
| `data.js` | 新增 `DOG`：`motion:"image"`、4 張圖片路徑、`facingLeft:true` 標記原始朝向（狗朝左，其餘 SVG 剪影預設朝右），加入預設啟用清單 |
| `animals.js` | 幀數從寫死 2 改成看 `frameCount(animal)`（狗是 4）；鏡射邏輯從「CSS 選擇器猜方向」改成 JS 依 `facingLeft` 算出 `mirror`，避免猜錯 |
| `style.css` | `img` 補 `object-fit:contain`；拿掉舊的猜方向 CSS 規則，改用 JS 控制的 `.animal-frame--mirror` |

**驗證**：
- `JSDOM.fromURL` 第三次卡住，直接放棄排查，認定是環境問題
- stub 環境確認：排入計時器數量正確（換幀+離場各 1 個）；手動觸發 4 次換幀，順序是 `dog_1→2→3→4→1`，沒卡住或亂序
- `Math.random` mock 測左右移動各一次，確認鏡射方向相反——**第一次寫測試時 mock 命中錯的隨機呼叫，出現過相反結果，修正 mock 邏輯後才確認程式碼本身沒問題**
- ⚠️ 動畫節奏、真實插畫跟其餘抽象剪影搭不搭，都還沒人看過
