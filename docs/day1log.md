## 2 · 心情日誌空白 bug

**現象**：面板打開只有標題，內容不見。

**原因**：`.overlay{display:flex}` 優先度打平 `[hidden]`，author stylesheet 蓋過瀏覽器預設。全站 7 個 modal 共通問題。

**修法**：

```css
[hidden] { display: none !important; }
```

**學到**：jsdom 不算 cascade，抓不到這類問題，要換真瀏覽器 DevTools。第一輪錯了就認錯，不硬凹。

詳見 `docs/appearancebug.md`。
